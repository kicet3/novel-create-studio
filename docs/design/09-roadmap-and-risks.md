### 2.2 의존 관계와 임계 경로

```
MA-0 기반·스파이크 ─┬─ MA-1 실행·비용 ─────────────┐
                    └─ MA-2 온톨로지 코어 ─ MA-3 링킹·추출·검사 ─┤
                                                                ├─ MA-4 화 파이프라인(웹 인박스) ─ MA-5 HITL·Telegram ─┐
                                                 MA-6 운영·설치·UI (MA-1 이후 병행 가능 부분 있음) ───────────────────────┴─ MA-7 MVP-α 검증
MA-7 ─ MB-0 템플릿 준비(D-30 (ii)) ─ MB-1 Discord·경합 ─ MB-2 다중 시간선·용어집 ─ MB-3 자율성 확장·규모 ─┬─ MB-4 MVP-β 검증
                                                                       └─ MB-5 self_hosted·Windows (병행)
MB-4 ─ V1-1 품질·HITL 확장 ┐
       V1-2 온톨로지 UI·다중 작품 ┼─ V1-5 v1 검증 ─ V2-0 공급자 재조사 ─ V2-1 ─ V2-2 ─ V2-3
       V1-3 씬 프롬프트 ─ V1-4 이미지 ┘
       [트랙 C] 템플릿 V1-T (FR-NOV-03c, 75~95인일) ┘
```

임계 경로: MA-0 → MA-2 → MA-3 → MA-4 → MA-5 → MA-7. 식별 계층(MA-2·MA-3)이 화 파이프라인(MA-4)의 선행이므로, 이 구간의 지연이 MVP-α 전체 지연이 됩니다(DR-03).
