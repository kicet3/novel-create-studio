**표기 규칙**
- 00 표기 규칙을 따릅니다. **가정:** 은 조사나 실측을 거치지 않은 전제입니다.
- 위치는 "문서 번호 절"입니다. 예: `06 3.8` = `06-story-ontology.md` 3.8절.
- 상태 정의
  - **설계됨**: 수용 기준을 만족하는 데이터·흐름·검사가 설계 절에 정의돼 있습니다. 값 보정(가정)이나 스파이크 확인이 남아도 설계됨으로 봅니다.
  - **부분**: 일부만 설계됐거나, 수용 기준 일부가 빠졌거나, 설계가 미결로 남아 수용 기준에 영향을 줍니다.
  - **누락**: 설계 절이 없습니다. 로드맵(09) 배정만 있는 경우도 누락입니다. 릴리스가 "이후"인 항목은 "누락(범위 밖)"으로 적습니다.
- 추출 방법: PRD 6·7절 표에서 `| FR-`, `| NFR-`로 시작하는 행 전부(PRD v0.5 기준 FR 150행, NFR 32행, 합계 182행. v0.4 초안은 FR 148행, v0.3은 FR 142행)를 뽑고, 설계 문서 00·02~11과 계획서에서 각 ID와 해당 기능 이름을 검색한 뒤 절 내용을 확인했습니다.
