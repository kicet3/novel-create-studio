3단계 · 자율성 수준 선택나중에 설정에서 변경 가능

자율성 수준(AutonomyLevel)은 사람 승인 게이트의 위치를 정합니다. 질문 민감도와는 독립입니다. 변경 이력은 감사 로그에 남습니다.

모든 수준에서 항상 사람 승인 — 기존 approved 사실 변경 · 리트콘(published_locked 변경) · 결말 방향 변경 · 예산 하드 한도 도달 후 재개 · 떡밥 폐기. 떡밥 기한 연장은 수준과 관계없이 질문으로 갑니다.

게이트 비교 (6.3.1)필수 = 승인 없이는 진행 안 함 · 없음 = 진행하고 기록
